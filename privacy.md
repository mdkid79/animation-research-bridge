# Privacy Policy

Last updated: September 28, 2026

## Purpose and operator

Animation Research Bridge is a personal research workflow operated by
GitHub user mdkid79. It uses Rclone to download files from the operator's
Google Drive to a private NAS for research archiving.

## Google data accessed

The application requests read-only access to Google Drive file contents
and metadata. This permission can allow access across the authorized
account; the download job is configured to copy only the
AnimationResearchInbox folder and its subfolders.

The application does not upload, modify, or delete Google Drive files.

## Use and storage

Downloaded files and metadata are used for personal research archiving
and knowledge management. Copies are stored on the operator's private NAS.

OAuth credentials and tokens are stored in the NAS configuration so that
scheduled downloads can run. They are not published on this website or
in its public GitHub repository.

## Sharing

This download workflow does not sell Google user data or send downloaded
files to advertising or analytics services. Files are transferred from
Google Drive to the operator's NAS.

Google user data accessed through this workflow is not used to train
general-purpose AI or machine-learning models.

## Retention and deletion

Local copies remain on the NAS until the operator deletes them.
Deleting a file in Google Drive does not automatically delete its NAS copy.

The operator can stop scheduled downloads, delete local files and
credentials, and revoke the application's access through
[Google Account connections](https://myaccount.google.com/connections).

Revoking access stops future authorized access but does not remove
previously downloaded local copies.

## Website hosting

This informational website is hosted by GitHub Pages. It does not
receive Google OAuth tokens or research files. GitHub may process
website visitor information under its own privacy statement:

[GitHub Privacy Statement](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement)

## Contact

For privacy questions, contact the operator through
[the GitHub project issues page](https://github.com/mdkid79/animation-research-bridge/issues).
Do not include credentials or private research data in public issues.
