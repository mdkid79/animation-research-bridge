# Animation Research Bridge

Animation Research Bridge is a private research workflow operated by
GitHub user mdkid79. It uses Rclone to download research briefings and
related files from the owner's Google Drive to a private NAS.

## Google Drive access

The application requests read-only access to Google Drive file contents
and metadata. Its configured download source is the owner's
AnimationResearchInbox folder.

It does not upload, modify, or delete files in Google Drive.

## Local storage

Downloaded files are stored on the owner's private NAS for research
archiving and use with a personal Obsidian knowledge base.

This website contains project information only. It does not receive
Google OAuth tokens or downloaded research files.
